## 结论

- 终端字节流：1 MB 输出的托管分配从 1561997 字节降到 40 字节（着色结果直接借用缓冲区、通道缓冲走对象池，不再每屏复制）。
- 远端监控采样解析：单次从 1.59 ms 降到 0.34 ms（约 4.7 倍），分配从 342801 字节降到 73954 字节（约 4.6 倍）。
- 多连接：10 个连接各每 2 秒采一次样，合计约占单核 1%，每秒产生约 182 KB 垃圾。
- 连接全部关闭后托管内存增长 0.0 MB，25 次连接/关闭没有发现泄漏。
- 发布版空闲时平均 CPU 0 %，工作集约 140.9 MB（主要是 Avalonia 与 AOT 运行时本身）。
